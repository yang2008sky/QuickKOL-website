# 创建 YouTube 频道前，先确定谁拥有系列节目

状态：本地审阅稿；正式发布日期待确认。

用品牌与创作者的长期职责决定在哪里发布赞助系列，再安排账号权限和验收。

![创作者在器材工作室设置相机准备拍摄系列节目](../public/assets/blog/create-youtube-channel-kol-series-ownership.jpg)

品牌准备和达人拍 YouTube 系列时，先选发布地点。若买的是达人已有节目的赞助，原频道和播放列表通常已经能满足交付。若品牌要长期保留自己的节目并轮换主持人，新频道可能更合适。由预定的长期所有者走官方创建流程，用委托角色安排拍摄、发布和数据。交接前用一条样片检查谁能上线、谁能报数，以及合作结束时谁继续管理。

## 先判断需要新频道还是现有频道里的系列

品牌、达人和代理先谈活动结束时谁会继续发布、谁持有频道、谁负责回复受众。新建频道有启动和维护成本。若品牌只赞助达人的四条现有节目，发在达人频道并用播放列表组织，往往可以保留原有观看关系。[YouTube 播放列表说明](https://support.google.com/youtube/answer/57792?hl=en)介绍了建立与管理播放列表的方法。它适合把系列集中在一处，但公开可见范围、剪辑和广告许可仍需在合同里核对。如果是品牌长期节目，由多人轮流主持，且品牌需要在换主持后保留频道，独立渠道可能更便于交接。

把选择写成一条明确承诺。例如「三期先发在达人频道，品牌取得九十天约定的剪辑使用权」，或「品牌持有频道，主持人提供拍摄和出镜，制作团队依权限交付」。比较两种方案需要的审批、对外品牌、素材控制和衡量能力。使用[达人报价和素材使用权框架](https://www.quickkol.com/zh/blog/creator-rates-usage-rights/#answer)，核对系列发布与后续使用的价格。别因为对方提供发片服务，就推断频道也随服务归品牌。

## 由正式所有者创建频道

[YouTube 创建频道指南](https://support.google.com/youtube/answer/1646861)区分个人频道和可多人管理的业务或其他名称频道。在电脑或移动网站登录准备承担所有权的账号。个人频道可以从头像进入设置，在账号管理区域选择新增或管理频道，创建时填头像、名称和手柄。业务或其他名称的路径从频道列表进入，可创建新频道或选择有权管理的 Brand Account。若某 Brand Account 已有频道，选择它可能切到已有频道。提交前看清当前账号和待创建对象，避免把活动加到旧频道里。

创建后确认显示名称、手柄、头像和 URL。以频道切换器回到刚建的频道，查 [YouTube 频道 ID 说明](https://support.google.com/youtube/answer/3250431?hl=en)确认记录字段。创建者保留恢复方式和账号责任，代理可以协助整理命名和头像。品牌长期运营的账号应该由品牌授权的人负责。不要先让临时制作人员用自己的账号建号，再以为发邮件就可以把权限和所有权转交。

## 给制作、发布和分析各自的权限

[YouTube 频道权限说明](https://support.google.com/youtube/answer/9481328?hl=en)介绍在不用交出 Google 账号的情况下委托频道访问。创建后在 YouTube Studio 查看权限入口，邀请相关人前先列任务。制作方可能只负责给品牌交文件；上线协调人要上传草稿；最终发布人要确认时间和素材；分析员需要适当的数据访问。不要因为某人需要一项报告就给整套管理权限。按当前产品显示的角色能力决定适合级别，尤其看可见收入、发布和管理权限是否需要。

让每个被邀请人用自己的账号接受，并执行一次与角色匹配的测试。比如剪辑师确认能上传约定的非公开草稿，分析员仅验证能看到约定的数据，品牌所有者负责发布和撤销。把邀请和接受时间、权限范围、结束日和撤销人写到内部表。人员换岗时先补齐新职责，再收回旧访问；品牌不应该把验证码或管理员密码发给制作群。

## 让频道身份与系列信息可核验

准备头像、频道简介、系列介绍、可公开的联系途径与其他官方站点链接。确保名称和手柄不会让受众误以为是另一位达人、主办方或品牌。品牌节目由达人主持时，在频道简介说明角色，分开列品牌与主持人的公开渠道。节目名称后来改变也保留唯一频道 ID。对照 [YouTube 频道身份核验方法](https://www.quickkol.com/zh/blog/youtube-channels-identity-scope-handoff/#answer)，确保网站、合同和节目发布页引用同一账号。

让一位未参与建立的人从品牌官网或创作者简介进一次频道。问他是否能找对节目、分辨主办和主持、找到适合的联系路径。若品牌负责客服，而达人仅负责出镜，明确由品牌处理产品请求。旧赞助链接不适合自动沿用到新频道，尤其是目标地区或利益关系改变时。确认公开的联系邮箱由有人负责且能在交接时转移。

## 用一条样片走通发布流程

正式开播前，用团队有权使用的样片验收。上传时确认选中的频道、文件版本、标题、缩略图、说明、字幕和可见性设置。任何测试视频的可见性以团队已批准的范围为准。让指定发布者从审稿状态核对时间、链接和播放列表，再按活动要求发布。创作者在节目中有实质商业关系时，由负责人按适用地区核对披露；[FTC 的达人披露指南](https://www.ftc.gov/business-guidance/resources/disclosures-101-social-media-influencers)给出美国语境下的可见性原则。素材使用音乐或第三方片段时，提前确认拟发布和拟投放用途。

让两个不同的角色检查结果。一个从发布端核对实际状态，一个从观众端打开链接、看能否按预期播放、标题和说明是否正确。避免用发布者能看到草稿的状态代替公众能播放。若试片先发错频道，按所有者的流程处理并记录已分享链接和访问影响。只在正确渠道重建或更正后才通知合作团队新链接。

## 首发前确定报告和访问边界

品牌想验收的可能是三集节目、目标地区访问或部分视频的使用权，指标不需要都用频道订阅数。给每集建一行：视频 ID、最终文件、发布账号、首发时间、披露、链接、投放许可、复查期。另指定数据所有者按相同时间窗提供平台报告。新频道没有稳定基线时，先记录样片触达、观看和去往目标页的动作，避免套用主频道或陌生账号的预期。以[创作者活动衡量方法](https://www.quickkol.com/zh/blog/creator-campaign-measurement/#answer)确定数据单位。

假设品牌在自有账号发布，达人从自己的频道引流。自有频道的视频表现和达人侧引流报告分别保存。对于同一观看者经过两条路径，平台聚合报告可能无法跨频道去重，不要简单相加当独立观众。团队若购买了原素材，交接时仍查已批准的用途、范围和期限，别用“已上线”覆盖所有权和投放决定。

## 把首发延期和达人交付一起处理

假设品牌拥有频道，达人负责主持、剪辑样片和在自己的社区做预告。样片里的产品文字需要更正，正式首发得推迟。先确认达人预告是否已经发出、观众会到哪一条链接、谁可以更新文案。品牌发布人处理频道排期，达人按原合同确认能否调整自己的预告。不能改的预告留记录，由双方批准相应更正。

把样片、更新文案、最终视频 ID 与实际首发时间连在一起。若合同购买的是制作和一次预告，复查它们各自是否已经交付，再决定延迟影响哪个条款。下一季如果改在达人账号发布，还需新确认账号、数据责任和品牌使用范围。这比只保存一个频道管理员名单更能帮助团队接手。

## 预演一次节目交接

试点最后做一次交接演练。假设代理结束服务或主持人更换，列出谁改片头、谁保留源文件、谁处理评论、谁能导出报表和谁撤回权限。所有者应能找到频道 ID、有效权限清单、版权与商业批准、未完成的视频和最终链接。确定是否需要更新介绍和联系方式。交接期间避免只保留一个暂时无法联系的人有关键访问。

如果下一季改由品牌运营，不要默认把旧达人的频道、观看历史或粉丝转给品牌。根据原合同，确定保留原频道上的节目、从旧内容链接到新系列，还是用允许的素材制作独立版本。先审查许可与可见性，再执行。对于尚未授权的片段，列出具体缺失并由相应负责人决定是否更换。用一次角色撤销和一次报告复查确认交接确实完成。

## 系列频道责任表

| 岗位 | 交付 | 验收 |
| --- | --- | --- |
| 账号所有者 | 创建、恢复、授权、撤销 | 确认频道 ID 和权限 |
| 节目制作 | 成片、字幕、缩略图 | 确认版本 |
| 发布人 | 发布、说明、披露和链接 | 打开观众端 URL |
| 分析 | 约定窗口和口径 | 查报表与视频 ID |

实际可用角色以当前频道权限页面为准。

## 首发检查清单

由频道所有者和发布者完成同一份验收。

- [ ] 确认是否确需新频道及其长期所有者。
- [ ] 记录手柄、频道 ID 和联系人。
- [ ] 逐一验证委托角色与样片。
- [ ] 确认首发、指标与离场处理。
