# YouTube 频道：核对账号身份与合作范围

在交接 YouTube 合作时区分频道、Handle、播放列表和授权人。

YouTube 频道是账号在平台发布与组织内容的身份。合作交接时，分别记录频道 ID、当前 Handle、作品实际上传方和商务授权人。播放列表或网络归属可以帮助发现内容，但需要核对具体发布频道、实际签约方和团队操作权限，才能确定谁负责。

## 给一个实际合作建立账号记录

假设品牌要采购一条教程。商务联系方说会“发到我们的 YouTube”，但提案中只有一张播放列表截图。先问是哪一个发布频道、视频是否原创上传、在什么地区和语言、何时发布。把拟签约主体、公开身份、审核角色和财务联系分别记录。用[寻找 YouTube 商务联系路径指南](https://www.quickkol.com/zh/blog/find-youtube-channel-owner-business-email/#answer)，从频道和可确认的对外渠道核对联系人。

## 区分频道 ID、Handle 与显示名

[YouTube 频道 ID 帮助](https://support.google.com/youtube/answer/3250431?hl=en)说明每个频道有独立的用户 ID 与频道 ID，主要所有者可在高级设置查看。[YouTube 频道 Handle 帮助](https://support.google.com/youtube/answer/11585688?hl=en)说明 Handle 以 @ 开头，和显示名不同，也可以更改。交接表记录已核对的频道 ID、当前 Handle、显示名、公开地址和日期。不能确认 ID 时标待核。若以前只存昵称，检查相关视频的实际上传方，不根据相似名称或头像合并。保留旧名字和确认的新关系。

## 打开原视频核对上传方

[YouTube 播放列表帮助](https://support.google.com/youtube/answer/57792?hl=en)将列表定义为视频集合，也提到他人可在适当设置下添加视频。入选某个列表不等于列表所有者上传、授权或赞助了其中每条。打开作品本身，记录原上传频道、视频地址、发布时间和你看的时间点。假设网络用一个合集展示创作者作品，每条可能来自不同频道。播放列表可以保留为发现路径，上传方另列为事实。

## 将制作、发布和许可分给不同责任人

频道主持人、制作公司、经纪和账号管理员可能不同。让联系人确认哪一方可接受制作条款、哪一方能发布、哪一方能同意品牌使用。用[达人费率与使用权指南](https://www.quickkol.com/zh/blog/creator-rates-usage-rights/#answer)拆出原片、发布、衍生、广告和期限。若只买了某频道发帖，不能由频道关联关系推断品牌可以复制到其他账号。遇到共同制作时，对具体资产核对许可来源和适用范围。

## 核对能查看、能编辑与能发布的角色

[YouTube 频道权限帮助](https://support.google.com/youtube/answer/9481328?hl=en)介绍可以按角色授权，不需要共享 Google 账号。用实际账号核对当前角色、可见范围、编辑、发布与移除权限。请有权管理员核对，使用已批准的测试内容，避免碰到真实待发活动。外部代理只需看到某个工作内容时，优先检查是否已有更合适的交接途径。把账号恢复、人员离开和到期撤权写进运营记录，不在表中存密码。

## 用三个相似账号跑一次核对

假设 A 是“城市骑行”主频道，B 是“城市骑行维修”地区频道，C 是某机构整理的播放列表。提案写 A，合约草稿误写 C，待发链接在 B。先逐条确认频道 ID、对方联系人权限和预定发布范围。若双方原意是 A，让实际发布者重查排程并修正交接；若改为 B，先确认双方同意、地区和报告预期。不要因 C 包含 A 的作品就把 C 当成发布方。给三条记录写各自用途。

## 发完再核对版本、链接与报告

记录批准成片、实际链接、发布时间、频道 ID 或确认的公开标识、实际许可和报告负责人。打开链接验证频道与文案，记录是否公开、是否有地区差异和时间。若上线后更改标题或剪辑版本，留下变更时间与授权。活动结束时，同一视频的公开数据、创作者获准报表和品牌效果分别处理。一个视频被列表收录不产生独立的赞助交付。

## 把改名、迁移和退出交接放进流程

换代理、负责人或品牌归属时，让现有账号所有者与接手人核对实际频道和授权范围。保留历史链接，记录已失效的公共地址和替代位置。移交时列出正在审批的版本、未到期许可、待发内容和谁还可以操作。用日期区分此前的频道状态与今天的状态。

## 交付文件给制作、发布和复盘分别使用

假设制作经理把最终剪辑存到共享目录，运营只拿到一个播放列表，分析师已经为另一个地区的频道建立报表。先从已批准任务查真实发布位置，让运营核对频道 ID、文件版号和公开时间。分析师按实际视频建立记录，另写原报表为何需要修订。给制作经理的是修改后的交付范围，不需要发整个商务对话。若有两位能发布，指定一位主操作与一位备份，避免同一文件被重复上传。活动结束核查哪个帖子对应约定，其他频道是否只分享过链接。保留相同格式给下一批，但把实际账号重新填一遍。

## YouTube 频道身份交接

| 对象 | 核对资料 | 用途 |
| --- | --- | --- |
| 频道 | ID、当前 Handle、公开链接 | 确定发布身份 |
| 视频或列表 | 原视频、上传人和列表入口 | 区分来源和组织方式 |
| 商业和权限 | 授权人、角色、可用范围 | 确认谁能同意和操作 |

保留所见日期与更正依据。

## 频道合作核对清单

对准同一项交付逐条核查。

- [ ] 频道 ID、Handle 与昵称分别记录
- [ ] 确认每条视频的实际上传方
- [ ] 商务与发布权限均已确认
- [ ] 保留实际上线链接和版本
