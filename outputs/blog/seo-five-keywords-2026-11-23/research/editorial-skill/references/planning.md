# 关键词与批量策划

## 筛选竞品词

竞品有流量只能说明它值得调查，不能证明适合 QuickKOL。每词判断：

1. 搜索者是谁，是否可能需要达人发现、研究或筛选？
2. 内容是否对目标读者有用，能否自然连接产品任务？学习型内容不必马上转化。
3. 我们有什么可靠事实、示例、演示、分析或资源能提供额外价值？

给出“优先 / 辅助覆盖 / 暂缓”与具体原因，不强制流量、KD、CPC 区间或固定各类比例。缺少关键词工具时可先作编辑判断，不能填猜测指标。

## 核对搜索意图

查看目标市场与语言下当前 SERP，记录观察日期、来源和实际看到的 URL，读取足够的相关页面判断主流需求与遗漏。普通 web search 作为近似观察，不能冒充指定国家的精确 Google 排名。竞品提供的历史排名不能替代当前意图检查。

通常先检查前几个主要结果；混合意图、争议或高成本页面再扩大研究，不机械要求每个词读取相同数量的网页。可以缓存同一主题已读取资料，但不能把一个词的 SERP 无条件代表整个组。

| 类型 | 页面应兑现的承诺 | 不足时的处理 |
|---|---|---|
| 人物/达人名单 | 真实对象、官方账号/作品、相关理由、观察日期与范围 | 缺名单则继续研究或改为准确命名的指南，不能保留“Top N”空壳标题 |
| 搜索与筛选教程 | 输入、具体步骤、示例结果、判断标准与失败情形 | 不用泛化管理建议替代操作 |
| 工具/计算器 | 实际可用入口、输入输出、方法与边界 | 不能用博客代替工具；说明是否需要授权实现新功能 |
| 产品比较/替代 | 相同任务下的事实差异、适合人群、限制、核验日 | 不凭记忆编价格、功能或声称亲测 |
| 定义/方法 | 直接解释、适用范围、例子、常见误解 | 不强行扩写成产品销售长文 |
| 数据/案例 | 原始来源、方法、结果、有限结论 | 无数据则暂缓或缩小主张，不用假设冒充案例 |

## 与已有内容一起聚类

检索实际注册的文章标题、主词、slug 和核心答案；不能只做关键词精确匹配或只依赖 `site:`。

- 同意图近义词可以映射到同一计划页面，记录一个主词及相关词。
- 同主题不同任务保留独立页面，说明各自独有答案及相互链接关系。
- 已有页面能完整回答时，标记“已覆盖”；新增真正独立的需求，或在授权范围内更新，不硬编区别。
- 同一关键词出现在多页不自动证明竞争；有 GSC 时查看查询与页面关系，无数据标为待验证。
- 不自动合并、替换或重定向历史文章。即使用户要求新增，也应暂缓缺少独立价值的重复题，不换 slug 复制正文。
- 系列文章不因主题相同就 canonical 到主篇。独立文章通常自指，重复/高度相似版本才评估 canonical。

## 选题卡与覆盖台账

先为整批生成一张表；详细研究可按页面另存。最少字段：

| 字段 | 说明 |
|---|---|
| input_id / original_keyword | 每个原始输入的稳定编号与原文，保留重复输入 |
| competitor_url / metric_source / observed_at / market / language | 已提供的数据出处与观察环境；缺失留未知 |
| priority / reason | 优先、辅助覆盖或暂缓及依据 |
| cluster / primary_keyword / related_keywords | 主题组及页面负责的需求 |
| reader / core_question / page_type | 谁需要什么交付 |
| existing_pages / differentiation | 已有覆盖及新增价值 |
| action / target_slug | 新增、同页覆盖、已覆盖、建议更新或暂缓；理由明确 |
| evidence / unique_value / product_next_step | 资料线索、独有价值与产品衔接 |
| status / deliverable | 研究、草稿、待验收、已接入等及文件位置 |

一个页面覆盖多个词时，所有词都回指同一个页面，但不能算成多篇已完成文章。优先级与状态分开：优先词也可能缺资料暂未写成。

先确定整批关系，再按主题/类型分组研究写作。首组覆盖有代表性的类型，检查后沿用有效做法，修正无效模板；不要求用户逐篇批准。保存每组的稿件与状态后继续，避免上下文变长造成漏词、来源丢失或后半批缩水。

用户只提供 40 个词时可继续策划，不要求另行填写大量表单。不能确定市场等关键条件时，提出最少的问题，继续不依赖答案的工作；未回答不能伪称已核验该市场。

## 后续复盘

交接时保留批次、URL、目标查询、发布状态与拟观察项目。有数据权限时，后续分别检查索引、查询展示/点击、产品入口行为与来源转化；按发布时间和意图分组，不把不同年龄文章直接横比。

无 GSC/分析权限就标记未验证，不能写“没有流量”。不因几天无表现立即批量重写或改日期。复盘建议不自动创建定时任务、付费查询或新增埋点。
