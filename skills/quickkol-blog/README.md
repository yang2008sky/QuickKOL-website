# quickkol-blog 执行说明

交付版本：1.2.0 · 2026-11-24

这是一套完整的 QuickKOL 博客技能。它保留详细写作规格，加入关键词批量策划、已确认的白底阅读样式和配图语言检查。无需同时加载旧版技能、旧编辑手册或此前聊天。

## 安装与调用

将整个 `quickkol-blog` 文件夹放入执行项目的 `.agents/skills/`，或执行者自己的 `~/.codex/skills/`。保留 references、assets、scripts、agents，目录结构不变；选择一个安装位置，避免保留多个不同版本。已有同名技能时先备份，再替换整个技能文件夹，不覆盖项目内容。

然后明确调用 `$quickkol-blog`。不支持技能自动发现的工具，可以让它读取本文件夹的 SKILL.md，再按入口链接读取相关参考文件。不要只复制 SKILL.md 后丢掉附件。

## 可以直接给执行者的任务

```text
使用 $quickkol-blog，为 QuickKOL 处理下面的关键词。
产品：QuickKOL 是 AI 找达人工具，具体能力按当前官方资料核验。
关键词及已有竞品资料：[粘贴]
目标市场、语言：[填写已知要求；未指定语言默认中英文]
目标仓库或工作副本：[填写；没有则先交可审阅稿件]
交付范围：[策划/写作/配图/接入本地网站]
远端和上线授权：[仅在需要推送或上线时填写]

先处理相关性、搜索意图与已有覆盖，给每个输入词记录去向；
按详细写作规格完成正文、证据和双语，不逐篇停下等待确认。
网站采用技能内已确认的白底字体与目录规范，保留既有组件结构。
含文字配图分语言交付，填写资源清单、运行预检并在实际页面看图。
完成单篇与整批验收，准确说明已完成阶段、缺口及文件位置。
```

仅调整旧文排版时明确写：

```text
使用 $quickkol-blog，仅调整这篇旧文的阅读样式：采用配套白底字体、
层级字号、颜色、间距和紧凑目录。保留正文、标题文字、章节顺序、
封面、表格及工具。先给本地预览，不推送或上线。
文章：[URL 或文件]
```

## 文件职责

| 文件 | 用途 |
|---|---|
| SKILL.md | 工作范围、流程和参考文件入口 |
| references/planning.md | 关键词筛选、意图、聚类与整批覆盖台账 |
| references/writing.md | 篇幅、文章类型、来源、内链、双语和元数据细则 |
| references/reading-layout.md | 已确认的白底、字体、字号、间距及无编号紧凑目录 |
| references/figure-localization.md | 配图分语言、资源映射、预检和页面验收 |
| references/delivery.md | 资源、当前站点接入、构建与交接 |
| assets/blog-reading.css | 配合现有站点使用的增量样式；按实际选择器适配 |
| assets/figure-manifest.csv | 空表头模板，填写本批实际资源 |
| scripts/check-figure-languages.py | 配图文件和 SVG 语言预检，Python 3.9+，无需安装包 |
| agents/openai.yaml | Codex 展示名称和默认调用提示 |

CSS 不会因为安装技能就自动作用于官网。需要网站接入授权时，按项目结构实际导入并验证；不要把本地预览控制条、noindex 或预览脚本带到生产。

图片预检通过不等于视觉验收通过。栅格图和实际页面资源选择仍要检查。没有浏览器或联网能力时，完成可做的工作并列明未验收项，不伪称完成。
