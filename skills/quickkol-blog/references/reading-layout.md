# QuickKOL 白底阅读样式

2026-11-23 用户以旧文章白底样张确认的项目视觉默认。适用于 QuickKOL 博客，不是通用 SEO 标准。后续明确的用户或设计要求优先。

## 保留什么

保留原有文章内容、标题文字、章节顺序、目录条目、封面、表格、工具和站点结构。只改字体、文字颜色、字号、字重、行高、间距与阅读背景。不要自动使用上一版重写样张的短标题、表格前置、段落压缩或新页面布局。

摘要/重点框和品牌 CTA 可保留原有组件外观；黑色页头、页脚不要求跟随阅读区变白。深色 CTA 内保持浅色文字，不能全局套深色标题导致低对比。表格/输入框用中性白灰取代米黄色，不改字段与交互。

## 字体和颜色

- 字体栈：`Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。
- 测试页使用本地可用字体回退；声明 Inter 不代表已下载或已实际使用 Inter。复现时检查 computed style 与可用字体，不擅自新增字体供应商或替换站点字体加载策略。
- 阅读区及文章标题区：`#FFFFFF`；主标题、小标题、正文：`#20211F`。
- 副标题/文章导语：`#666963`；辅助文字约 `#777B72`；链接及重点蓝：`#2359DC`。
- 不把“封面使用奶油色”扩展为“正文必须使用米黄色背景”。

## 层级参数

| 元素 | 桌面默认 | 手机默认（不大于 760px） |
|---|---|---|
| 英文 H1 | 35–54px 响应式，字重 750，行高 1.12 | 36px，行高 1.15 |
| 中文 H1 | 33–49px 响应式，行高 1.3，适度均衡换行 | 最低 33px，行高 1.3 |
| 副标题/导语 | 20px，行高 1.55 | 17px，行高 1.65 |
| H2 | 29px，字重 730，上/下间距 48/19px | 26px，上间距 38px |
| H3 | 24px，字重 700，上/下间距 27/10px | 22px |
| 普通正文 | 18px，行高 1.78，段后 20px | 17px，行高 1.8 |
| 中文普通正文 | 与对应字号一致，行高 1.9 | 与对应字号一致，行高 1.9 |
| 开头答案正文 | 21px，行高 1.6，与正文同字体栈 | 19px |

英文标题适度紧字距，中文标题与正文减少负字距。标题不留单字/单词孤行；根据语言和屏幕检查换行，不靠手工插入固定 br 适配单一屏幕。保持原版正文列宽与页面布局，除非用户另行要求调整。

## 目录

- 默认**不加数字序号**：摘要、正文、工具、来源是文章位置，不是连续操作步骤。用户明确要求编号或文章确实是分步流程时再采用，避免把数字写入标题正文。
- 使用紧凑条目：12px，行高 1.45，每项上下 padding 6px，取消原有 15px 条目上外边距；目录标签下间距 12px。
- 使用连续、轻量的左侧引导线，当前章节或悬停使用蓝色；避免每条分开的大段竖线和大量空白。
- 长标题允许自然换行，不用省略号隐藏关键信息。保留原有锚点与条目顺序，目录高亮应对应实际位置。
- 手机上保持现有目录布局，长表格只在自己的容器横向滚动，目录不能撑宽整页。

## 实现与验收

配套 [增量样式](../assets/blog-reading.css) 面向当前 `.blog-page`、`.blog-article-*`、`.blog-toc` 结构，放在现有站点样式之后；先核对选择器和断点，再最小适配。不要把本地样张的控制条、noindex、静态预览脚本带到生产。

写 Markdown 或文章数据本身不能落实字体和背景。若任务不包含站点样式接入，交付内容并说明呈现由渲染器负责；不要为套用视觉规则擅改全站。

验收至少覆盖一个桌面和约 390px 手机宽度、所交付语言：实际字体/颜色/字号、标题换行、目录高度与跳转、白色阅读背景、深色组件对比度、表格/工具可用性。仅样式任务比对原文与新页的内容和顺序一致。保存截图；未视觉检查不能声称排版通过。
