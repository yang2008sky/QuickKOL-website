# 配图语言交付与检查

## 失败案例与要解决的问题

英文文章曾加载中英混排、中文为主的 SVG。alt 与图注已经是英文，图片也加载成功，但图片内部标题和标签没有匹配页面语言。验收必须覆盖资源内容和页面实际选用的资源，不能只数文件、看 alt 或请求是否返回 200。

## 先选择合适的呈现方式

比较、字段映射和对应关系优先采用 [精简表格](tables-and-diagrams.md)，不要把多行文字列表导出成SVG或图片。原生表格和流程组件由页面语言机制本地化，不计入图片清单；仍需在真实页面验证。只有确实承担视觉解释任务的图形才按下列图片流程交付。

## 准备资源

- 自制含文字图按语言分别交付，例如 `role-map.en.svg`、`role-map.zh.svg`。英文版使用英文说明，中文版使用中文说明；姓名、品牌和必要原词可保留。无文字的编辑图、照片可以共用。
- 不默认使用中英混排图同时满足两种语言交付。不为纯装饰图添加无用文字。标题、正文图、图例、坐标轴、单位和小字注释都属于检查范围。
- 桌面横版图在手机上不可读时制作相应竖版或简化版，分别记录文件；不能只确认图片没有溢出。
- 原始截图确有编辑需要时可保留原语言，说明出处和读图含义，标为 `screenshot`；这不允许自制图绕过本地化。不能修改截图来伪装产品已有另一语言界面。
- 其他语言缺少对应图时，使用合适的无文字图或标记待完成，不能静默回退中文图。

## 资源清单

复制 [figure-manifest.csv](../assets/figure-manifest.csv) 的表头，在本次输出目录填写实际条目。一行对应一个语言/版位/设备资源：

| 字段 | 含义 |
|---|---|
| article_slug | 所属文章 |
| page_locale | 目标页面语言，例如 en、zh-CN |
| placement | cover、inline、social 等实际版位 |
| asset_path | 相对项目根目录的实际文件路径 |
| text_mode | text（自制含文字）、no-text（无文字）、screenshot（原始截图） |
| alt / caption | 对应页面语言的实际替代文字与图注 |

设备版可用 placement 如 inline-mobile 区分。清单不是新的站点内容 schema，不直接把这些字段塞入文章数据；按项目已有接口接入。

## 预检

从项目目录运行，将技能目录替换成实际安装位置：

```bash
python3 /path/to/quickkol-blog/scripts/check-figure-languages.py \
  --root /path/to/project \
  --manifest outputs/blog/batch/figure-manifest.csv
```

脚本只使用 Python 标准库，不联网、不改资源。manifest 相对路径以 root 为基准，asset_path 也以 root 为基准。JSON 输出逐行状态：

- `fail`：缺文件/字段无效、英文自制 SVG 检出 CJK 文字、无文字声明与 SVG text 元素冲突等。先修再继续。
- `review`：PNG/JPEG、截图、路径化 SVG 文字或未支持的语言等不能自动证明正确的项目。必须实际看图记录判断。
- `pass`：在脚本限定范围内未发现问题，仍需检查渲染器和页面。

退出码 0 为全部预检通过，1 为存在 fail，2 为无 fail 但存在 review。不得把 2 当作交付失败后跳过图片，也不得把 0 写成“所有图片已视觉通过”。脚本对英文/中文 SVG 做文字脚本检查，不证明翻译质量、词义、像素可读性或嵌入图片内容。

## 接入页面

SVG 是独立资源，翻译网页不会翻译外部 img 中的文字。检查项目是否支持按 locale 选择图：

- 如果只支持一个 `figure.file`，创建两个文件仍然不够。需要在授权范围内补最小语言资源映射，并保留原有单文件兼容。
- 不传数组或新增未支持字段后就宣布完成。检查实际渲染分支。
- CSS 也不会翻译图中文字。用 picture 时检查浏览器选中的 currentSrc，不只看 img.src。

## 页面验收记录

对每种交付语言、桌面与手机逐图记录：页面 URL/语言、预期文件、实际 src/currentSrc、实际看见的文字语言、是否清晰、alt/图注、截图位置、结果及问题。

先滚动到图片让懒加载发生，再看图。自制英文图出现中文说明、只创建文件未接入、手机图中文字不可读，都不能算完成。复用旧资源同样检查，不因它已上线就视为合格。只改排版时若发现既有图片问题，单独记录，不擅自重做整站资源。
